There are two ways: the administrator gives you a new temporary password, or, if you have a recovery code, you get in by yourself with it.

## Ask for a temporary password
Ask the owner or someone who manages the accounts. They can reset only an account that does not have more permissions than theirs. They:
1. Click their name at the top right, then **Settings**.
2. Click **Accounts**.
3. In your row, click **Reset password**.
4. The temporary password appears at the top. They give it to you.

Then you:
1. At sign-in, enter your username and the temporary password, then **Sign in**.
2. **New password** opens. In **Current password**, enter the temporary one.
3. In **New password** and **Repeat password**, enter your own, at least 8 characters.
4. Click **Change and continue**.

After the reset, every place where you were signed in is signed out, and your PIN is deleted. If you switched with a PIN, set a new one in **My profile** and ask the administrator to turn the PIN back on — see [How do I change my password, PIN, theme or language?](../moj-profil/).

## With the recovery code
The account the company was set up with got a recovery code during setup. Any other account can make its own code in **My profile** — see below. The code is shown only once, so it can be printed. With it you get in without anyone else.
1. At sign-in, click **Forgot your password?**.
2. In **Username or e-mail**, enter your username or e-mail — the same as when you sign in.
3. In **Recovery code**, copy the code from the paper. Capital and small letters and dashes do not matter.
4. In **New password** and **Repeat password**, enter a new password, at least 8 characters.
5. Click **Set a new password**.
6. The app shows a new **Recovery code**. Click **Print** or copy it down.
7. Tick **I have written the code down somewhere safe.** and click **Enter the app**.

> **Important**
> The old code is no longer valid — each code can be used only once. Keep the new paper somewhere safe, and throw the old one away. The new code cannot be seen again.

## Make yourself a recovery code
Make it while you still know your password.
1. At the top right, click your name, then **My profile**.
2. Under **Recovery code**, in **Current password**, enter your password.
3. Click **Make a recovery code**, then **Make a new code**.
4. The code is shown. Click **Print** or copy it down.
5. Tick **I have written the code down somewhere safe.** and click **Done**.

A new code replaces the old one — the old one is no longer valid.

## If it does not work
- "The recovery code or username is not correct." — check the username (or e-mail) and the code.
- "Too many attempts. Wait a few minutes and try again." — after a few wrong attempts, sign-in waits a few minutes.
- The main account does not have the recovery code: its password can be reset only by another account with the "Owner" role, as above. An administrator who does not have every permission cannot reset it, so keep the code — or make a new one in **My profile** while you still know the password.
