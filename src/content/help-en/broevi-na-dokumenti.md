A document gets a number when you issue it, for example 15/2026. Each document type counts on its own, from 1 every year. That is why Invoice 15/2026 and Quote 15/2026 can exist side by side.

How the number looks is changed in **Settings** → **Company**, at the very bottom, in **Document names and numbers**.

1. At the top right, click your name, then **Settings**.
2. Go to the very bottom, to **Document names and numbers**.
3. **How the number looks** holds the parts of the number: **Number** and **Year** are always there. Pick a sign between them: -, /, a dot, a space or nothing.
4. For a prefix (for example FAK-15/2026), click **Add a part** and pick **Prefix**. Each document type gets its own standard code. With the "Warehouse management" module there is also **Warehouse code** (for example M1-15/2026); you write the code on each warehouse — see [How do I add a new warehouse?](../magacini/).
5. In **Year format**, pick 2026 or 26.
6. In **Leading zeros**, pick whether the number is 15, 015, 0015…
7. Under them it says "Example": that is how the next number will look.

8. Click **Save** at the end of the section.

## Separately for one document type
Click **Settings per document type**. For each document type you can:
- write the prefix differently, if a prefix has been added;
- pick how the document's name is written in the lists and in the title on paper: **Full**, **Short** or **Custom text**.

Then click **Save**.

## No prefix
If you don't need the prefix, pick **Remove** in the **Prefix** field. The app asks first, because the prefix is deleted from all document types.

> **Important**
> The change applies from the next number. Documents already issued keep their number. If documents have already been issued this year, the order of the parts (for example year before number) can only be changed from 1 January.
